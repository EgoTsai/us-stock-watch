# 美股即時觀察站 (US Stock Watchlist)

清爽、簡潔的美股線上觀察面板，透過 GitHub Pages 與 GitHub Actions 全自動更新。

## 線上網址
- **GitHub Pages**: [https://egotsai.github.io/us-stock-watch/](https://egotsai.github.io/us-stock-watch/)

## 核心功能
1. **美國前 30 大科技股・聯準會重磅快報（每 3 分鐘自動掃描）**：採用華爾街財經入口網站（Bloomberg / CNBC / 富途 Moomoo）標準「頂部懸停暫停跑馬燈 ＋ 一鍵展開式 7×24 時間軸快訊匣」雙模式，嚴格過濾僅收錄美國前 30 大市值科技巨頭動態（當機、財報、併購、監管）與直接影響科技股估值的聯準會升降息／晶片政策。
2. **美股三大市場走勢與收盤**：道瓊 (`^DJI`)、納斯達克 (`^IXIC`)、標普 500 (`^GSPC`) 前一完整交易日分時走勢圖與收盤漲跌幅（**漲綠跌紅**）。
3. **美股頭條重點整理**：精選主流財經媒體重點條列，每則皆附原文連結。
4. **21 檔核心觀察名單（Firstrade / 富途 Moomoo 橫列式介面・每 3 分鐘即時更新）**：
   - **核心持倉優先置頂 (`★ 我的核心持倉`)**：`GOOG`、`TSM`、`TSLA`、`NVDA`、`TQQQ`、`BOXX`、`IAU`。
   - **自選觀察名單 (`☆ 自選觀察名單`)**：`VOO`、`QQQ`、`MSFT`、`META`、`SPCX`、`MU`、`AMD`、`AVGO`、`INTC`、`SOXL`、`IBIT`、`CL=F (NYMEX 原油)`、`UCO`、`VIX`。
   - 自動判別並顯示 **夜盤 / 盤前 / 盤中 / 盤後** 最新成交價與分時走勢線，並支援直接點擊表頭（漲跌幅、最新價、網友情緒、代號）即時三段式排序。
5. **個股 6 小時重點頭條（含中英雙層自動繁中翻譯）**：每列內嵌最新重點頭條並支援點擊展開完整明細與摘要；若外媒標題或新聞內容摘要含英文句子，後端與前端雙重引擎會自動翻譯為流暢繁體中文。每 6 小時自動更新，並於**美股開盤前 10 分鐘 (`09:20 ET`)** 強制刷新一次。
6. **個股 6 小時網友情緒指數**：綜合社群討論熱度、選擇權買賣權成交比與近 6 小時主動買賣盤量能，**想買居多顯示綠色百分比、想賣居多顯示紅色百分比**，同步於每 6 小時及美股開盤前 10 分鐘更新。
7. **投資長 (CIO & CRO) 專業操作建議**：依據最新盤勢、波動率 (`VIX`) 與期權防線動態產出持倉與觀察名單操作策略。
